What the Lab checks every turn

Every action — taken by a bot or by you — runs all of these. A red id in the check strip or the results table is one of these failing at that turn.

How to reproduce a failure

Runs are deterministic. The seed, policy, pack and action count identify a run exactly; Jump to turn replays the recorded choices to the failing step and drops you into the Watch pane there. Download save gives you the exact state to attach to a bug report; the terminal client resumes it with npm run play -- --resume <file>.
